# 술집·여관 손님

`MPCG.CDS` 파트 170 부터를 뽑은 것이다. `tools/extract_tavern_guests.py` 가 만든다.

손님 번호 = 파트 번호 - 170. 문화권 차례로 놓여 있다.

| 손님 번호 | 파트 | 문화권 |
|---|---|---|
| 000 ~ 038 | 170 ~ 208 | 유럽 |
| 039 ~ 074 | 209 ~ 244 | 중근동 |
| 075 ~ 080 | 245 ~ 250 | 아프리카 |
| 081 ~ 089 | 251 ~ 259 | 인도 |
| 090 ~ 106 | 260 ~ 276 | 동아시아 |
| 107 ~ 119 | 277 ~ 289 | 동남아 |
| 120 ~ 134 | 290 ~ 304 | 중남미 |
| 135 ~ 145 | 305 ~ 315 | 아메리카 |

비침은 색인 55, 팔레트는 사진 팔레트의 앞 64색(바이트 차례 파랑·빨강·초록)이다.
